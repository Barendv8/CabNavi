## 1. What CabNavi is

1.1 CabNavi is a heads-up display and trip logbook that runs as a native
plugin inside your own copy of Euro Truck Simulator 2. It reads data the game
already exposes through the SCS Telemetry SDK and the TruckersMP Client SDK,
and draws that data on screen.
