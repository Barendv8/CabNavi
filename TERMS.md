- **Plays by TruckersMP's rules.** CabNavi uses only the official TruckersMP

  reading only, never modified. See `PRIVACY.md`.

  `%APPDATA%\CabNavi\` in plain text and JSON; take it, back it up or delete

- **Third-party services.** Server data comes from the public TruckersMP Web
  API, the map table from this repository, and Discord notifications go to a
  webhook you provide. Their availability and terms are theirs. Both network
  features can be switched off in Settings.
- **Fuel prices, the map table and derived values** are read from your own
  installed game and are as accurate as that data; a newer map DLC may
  temporarily fall back to country-level detection until the table is
  refreshed.
